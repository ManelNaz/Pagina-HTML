Lista de comandos do Sistema

Abaixo está a lista dos atalhos configurados no Hyprland.

Shell & QS

Atalho Ação
Super + Tab Abre e fecha a visão geral dos aplicativos
Super + A Abre a barra lateral esquerda
Super + N Abre a barra lateral direita
Super + K Abre/fecha o teclado virtual
Super + M Abre/fecha o controle de midia
Super + G Abre/fecha a sobreposição de widgets
Super + J Mostra/oculta a barra de tarefas
CTRL + Super + T Abre o seletor de papel de parede
CTRL + Super + Alt + T Escolhe um papel de parede aleatório
CTRL + Super + R Reinicia o QS e os widgets

Zoom e Mídia

Atalho Ação
Super + - Diminui o zoom do cursor
Super + = Aumenta o zoom do cursor
Super + Shift + N Avança para a próxima faixa
Super + Shift + B Volta para a faixa anterior
Super + Shift + P Reproduz ou pausa a faixa atual
Super + Shift + M Ativa ou desativa o mudo
Super + Alt + M Silencia ou ativa o Microfone
